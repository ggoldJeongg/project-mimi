# PROTOCOL — Robot ↔ Gateway UDP 계약

> 이 문서 하나만 읽어도 실제 Robot과 Gateway가 UDP로 주고받는 데이터를
> **어떻게 보내고 어떻게 해석하는지** 알 수 있어야 한다.
> web ↔ gateway 사이의 WebSocket/JSON 계약은 여기 대상이 아니다 →
> `packages/protocol`(공유 타입)과 기획서 §7.1 참조.

관련 규칙: UDP 소켓 로직은 **gateway 안에만** 둔다. 브라우저는 raw UDP를 절대 만지지 않는다.

---

## 1. 통신 개요

```
Robot  ──(UDP, ASCII 문자열)──▶  Gateway   : Telemetry (현재 관절값)
Robot  ◀──(UDP, ASCII 문자열)──  Gateway   : Command   (목표 관절값)
```

- 전송 계층: **UDP** (전달 보장 없음)
- 페이로드: **ASCII 텍스트 문자열** (바이너리 아님)
- 대상 관절: 3축 — `J1`, `J2`, `J3`

---

## 2. 프레임 포맷 (확정)

### 2.1 Robot → Gateway (Telemetry)

```
J1;J2;J3;
```

- 각 값은 정수, 세미콜론(`;`)으로 구분, **각 값 뒤에 세미콜론이 붙는다**(마지막 값 뒤에도 `;`).
- 값 스케일: **`degree × 100`** (centi-degree).
  - 파싱: `degree = raw / 100`
- 음수 각도 지원: 값 앞에 `-` 부호.
- 순서 고정: `J1` → `J2` → `J3`.

**예시**

| Raw 문자열      | J1     | J2     | J3      |
| --------------- | ------ | ------ | ------- |
| `2450;1000;-725;` | 24.5°  | 10.0°  | -7.25°  |
| `0;0;0;`          | 0°     | 0°     | 0°      |
| `-9000;1800;-4500;` | -90.0° | 180.0° | -45.0°  |

### 2.2 Gateway → Robot (Command)

- 초기 방향: Telemetry와 **동일한 `J1;J2;J3;` 형식**으로 목표 관절값을 전송한다(값 스케일도 `degree × 100`).
- 로봇 데이터 송신 형식 : mcs;2000;2000;2000;
- node.js gateway 송신 형식 : target;2000;2000;2000;
- 로봇 명령어 stop : 모든 작동을 멈추고 힘을 풀어줌(모터)
- 세 축을 항상 모두 보내줘야함

---

## 3. 파싱 / 인코딩 규칙 (gateway 구현 기준)

**디코딩 (Robot → Gateway)**

1. 수신 문자열에서 trailing 개행/공백 제거.
2. `;` 기준 split → 빈 마지막 요소 제거.
3. 요소가 **정확히 3개가 아니면** 손상 프레임으로 간주하고 **폐기**(적용하지 않음).
4. 각 요소를 정수로 파싱, 파싱 실패 시 프레임 폐기.
5. `degree = raw / 100`.

**인코딩 (Gateway → Robot)**

1. `degree × 100`을 정수로 반올림.
2. `J1;J2;J3;` 형식으로 조립(각 값 뒤 `;` 포함).
